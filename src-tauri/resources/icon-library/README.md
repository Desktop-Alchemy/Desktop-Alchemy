# Icon Resources and Licenses

This directory contains images used to seed the personal image-asset library. The app copies their bytes into content-addressed storage. Deleting a library entry does not delete the installed seed resource. Retain the original license files with their assets.

## Common key glyphs

Base glyphs in `material-design-icons/` and `../key-icons/transparent/` are published by the Google Fonts Team under Apache License 2.0; see `licenses/Apache-2.0.txt` in the repository and installed `licenses/` directory. Project modifications include resizing, recoloring, and rasterization, with attribution/modifications in PNG metadata and license notes.

`arrow_back.svg` is the back-arrow vector. Its `png/` counterpart is a 256×256 image with a warm ivory background, dark brown arrow, and padding. Local generators apply consistent color, scale, and backing to other key glyphs.

## Social-media glyphs

The social glyphs are by Mads Egmose under Creative Commons Attribution 4.0 International. `social-media/color/` contains 26 color variants; `social-media/negative/` contains 26 white-on-black variants. Each 64×64 PNG is cropped from its source atlas. Preserve the author, license, and modification statements, including PNG metadata.

Brand names and marks identify their services and remain the property of their respective owners. Inclusion does not imply endorsement. Only resources actually present with the required licensing and processing are available in the app; unavailable collections and preview-only images are not bundled.
