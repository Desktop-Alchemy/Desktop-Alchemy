# Third-party licenses

This directory is the canonical repository location for license texts and notices. Use this index to identify the component, pinned version or source, license, and destination used when a distributable is created.

Do not remove notices from a distributable just because its canonical copy is stored here. Build scripts copy the applicable texts into each self-contained app, plugin, or model package. Generated copies under `plugins/performance/sensors/publish/licenses/` are part of the sensor payload and are regenerated by `pnpm plugins:build`; do not edit them directly.

## Updating license records

When adding or updating a dependency, put its canonical license text here and add a row to this index. Record the exact dependency version or commit and the upstream source. Update the relevant build step to copy the text into the deliverable under a readable name, then keep its package manifest/hash list in sync when one exists. Preserve separate notices and exceptions even if they accompany the same component.

The example projects and bundled icon/font/model assets have separate redistribution boundaries. A license being present in the app installer does not automatically place it in a separately packed example or model archive; use the package-specific build workflow recorded above.
